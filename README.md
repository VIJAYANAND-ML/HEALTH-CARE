# Healthcare Disease Prediction Model

## 🏥 Project Overview
This project focuses on predicting disease outcomes based on patient clinical indicators. By leveraging machine learning, we aim to assist in early diagnosis, ensuring high-risk patients receive timely intervention.

## 🚀 Key Features
* **Model:** Random Forest Classifier.
* **Optimization:** Used `GridSearchCV` for hyperparameter tuning.
* **Evaluation:** Focused on **Recall** to minimize false negatives in medical diagnosis.
* **Insight:** Identified key health markers (Glucose, BMI, Age) via Feature Importance analysis.
